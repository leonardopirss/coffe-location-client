# ☕ Café Office Web

## Sobre o projeto
O **Café Office Web** é a interface do usuário para explorar e encontrar os melhores cafés para trabalhar em Porto Alegre.  
A aplicação consome a API do backend e exibe uma lista de locais com base na localização do usuário, com um design responsivo e intuitivo.

## Funcionalidades
- Listagem de cafés cadastrados
- Exibição dos cafés mais próximos da sua localização
- Interface moderna e responsiva
- Integração com API Java Spring Boot

## Tecnologias
- React 18
- Axios
- React Router DOM
